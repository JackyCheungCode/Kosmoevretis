# Kosmoevretis

Global AI Business Discovery & Intelligence Platform.

## Current delivery

- Dashboard page at `/dashboard`
- React + TypeScript + Vite
- IBM Carbon foundation and visual language
- React Router with Cloudflare Pages SPA deep-link fallback
- Feature-first module structure

## Development

- `npm install`
- `npm run dev`
- `npm run typecheck`
- `npm run build`

See `docs/architecture.md` for module boundaries and routing principles. Each page is delivered and reviewed before the next module is built.
